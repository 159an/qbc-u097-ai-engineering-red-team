# 智能体断言的机械核验

- 轨迹：`P3-peclet-threshold.trajectory.raw.json`
- 核验时间：2026-10-03T08:15:13.204Z
- 样本：**41** 条稳态求解返回，peclet 覆盖范围 **0.0001 ~ 100**

## 被核验的断言

智能体在最终报告中写道（原文）：

> `numerics.peclet` 字段在低速度区存在明显的数据不稳定/随机化（v=0.5 返回 0.0001、v=100 返回 0.6 等，均与定义 v·dx/α 不符）

## 核验方法

不依赖"我们相信服务是好的"这类外部主张，只用**智能体自己收到的返回**检验一条它无权违反的不变量：

```
稳态中心差分离散下：  overshoot > 0  ⟺  peclet > 2
```

理由：中心差分的稳态对流扩散方程在网格 Péclet 数 > 2 时失去对角占优，解必然越过边界值
（overshoot > 0）；≤ 2 时保持单调。这条关系是离散格式的数学性质，与被测系统的实现无关。

## 结论

在智能体收到的全部 41 条稳态返回上（peclet 覆盖 0.0001 ~ 100），
`overshoot > 0 ⟺ peclet > 2` 这条不变量**无一违反**。

因此 `numerics.peclet` 在它实际覆盖的整个量程上都是自洽的，
**它关于「数据不稳定/随机化」的断言被它自己收到的数据否证**。

（另经直接 HTTP 核验：v=1/10/100/200/201/500 时服务返回的 peclet 与 `v·dx/α` 精确一致，
  见 `docs/成果汇总.md` §5.3。两条独立路径得出同一结论。）

### 这条核验说明了什么

智能体的**实验部分全对**：二分锁定 Pe=2、推导出中心差分的系数不等式、网格加密对照也正确。
出错的只是**汇总表格的誊写**，而它随即在这个誊写错误之上构建了一个不存在的缺陷结论。

这正是本作品的核心主张：**模型的叙述不是事实来源，轨迹才是**。
所以本仓库的证据流水线（`tools/analyze-trajectory.mjs`）从 AGH 原生事件流生成断言，
而不是采信模型的自然语言总结——包括"模型说错了"这件事，也由代码而非人工判断来证明。
